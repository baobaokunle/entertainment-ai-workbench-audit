# 一、当前产品目标

【用户确认】

帮助娱乐主播利用数据和AI，提高粉丝维护效率。

核心问题： 1. 谁需要优先回复？ 2. 谁值得重点维护？ 3. 谁需要保持关系？
4. 谁可能发生变化？ 5. 主播时间应该投入在哪里？

产品定位： 娱乐主播粉丝资产管理 + AI辅助运营系统。

不是自动聊天机器人。 不是自动发送工具。 不是替代主播的人。

# 十、Codex开发自动化原则

可以自动化： - 本地代码修改 - 测试 - 构建 - 文件整理 - 离线验证

需要确认： - 登录账号 - 平台访问 - 网络权限 - 安装软件 - 外部服务

数据采集原则： 本人登录、本地运行、只读验证。
不自动登录，不绕限制，不绕风控。
